# Quantitative Aptitude & Logical Reasoning 📊

Essential formulas, shortcuts, and pattern recognition rules for company placement assessments (Goldman Sachs, TCS, Infosys, Cognizant, Wipro, Accenture, Capgemini).

## 📐 High-Yield Quantitative Topics

### 1. Speed, Time, and Distance
- $\text{Speed} = \frac{\text{Distance}}{\text{Time}}$
- $1 \text{ km/h} = \frac{5}{18} \text{ m/s}$
- **Average Speed:**
  - If equal distances covered at speeds $x$ and $y$: $\text{Avg Speed} = \frac{2xy}{x+y}$
- **Relative Speed:**
  - Opposite directions: $S_1 + S_2$
  - Same direction: $|S_1 - S_2|$

### 2. Time & Work
- If A completes work in $n$ days, A's 1-day work = $\frac{1}{n}$.
- Total Work LCM method: Assume total units of work = $\text{LCM}(\text{time taken by each individual})$.
- **Pipes & Cisterns:** Inflow pipe is positive work, Leak/Outflow pipe is negative work.

### 3. Percentages & Profit/Loss
- $\text{Profit \%} = \frac{\text{Profit}}{\text{Cost Price}} \times 100$
- $\text{Loss \%} = \frac{\text{Loss}}{\text{Cost Price}} \times 100$
- Successive percentage change: $a + b + \frac{ab}{100}\%$

### 4. Permutations, Combinations & Probability
- $^n P_r = \frac{n!}{(n-r)!}$ (Arrangement / Order matters)
- $^n C_r = \frac{n!}{r!(n-r)!}$ (Selection / Order does not matter)
- $\text{Probability } P(E) = \frac{\text{Favorable Outcomes}}{\text{Total Outcomes}}$

## 🧩 Logical Reasoning & Puzzles

### Classic Interview Puzzles
1. **25 Horses Race:** Find top 3 fastest horses on a 5-lane track.
   - *Solution:* 7 races required.
2. **Heavy Ball Problem:** 8 balls, 1 is heavier, balance scale.
   - *Solution:* 2 weighings required (group into 3, 3, 2).
3. **Monty Hall Problem:** Switch doors to increase winning probability from $\frac{1}{3}$ to $\frac{2}{3}$.
4. **Burning Ropes:** Two ropes, each takes 60 mins to burn non-uniformly. Measure 45 minutes.
   - *Solution:* Light rope 1 at both ends and rope 2 at one end. When rope 1 burns out (30 mins), light the other end of rope 2 (15 mins). Total = 45 mins.

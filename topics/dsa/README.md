# Data Structures & Algorithms (DSA) Master Checklist 🧮

A topic-by-topic roadmap of patterns tested across top company technical interviews.

---

## 🗺️ Topic Patterns & Must-Solve Problems

### 1. Two Pointers & Sliding Window
- **Patterns:** Opposite ends moving inward, fast & slow pointers, variable window size, fixed window size.
- **Must-solve:**
  - [x] Two Sum II - Input Array Is Sorted (LeetCode 167)
  - [x] 3Sum (LeetCode 15)
  - [x] Trapping Rain Water (LeetCode 42)
  - [x] Longest Substring Without Repeating Characters (LeetCode 3)
  - [x] Minimum Window Substring (LeetCode 76)

### 2. Binary Search
- **Patterns:** Search in rotated arrays, search in matrix, binary search on answer space (predicate monotonicity).
- **Must-solve:**
  - [x] Binary Search (LeetCode 704)
  - [x] Search in Rotated Sorted Array (LeetCode 33)
  - [x] Koko Eating Bananas (LeetCode 875)
  - [x] Capacity To Ship Packages Within D Days (LeetCode 1011)
  - [x] Median of Two Sorted Arrays (LeetCode 4)

### 3. Linked Lists
- **Patterns:** Fast & slow pointers (Hare & Tortoise), in-place reversal, dummy head technique.
- **Must-solve:**
  - [x] Reverse Linked List (LeetCode 206)
  - [x] Linked List Cycle II (LeetCode 142)
  - [x] Merge Two Sorted Lists (LeetCode 21)
  - [x] Reorder List (LeetCode 143)
  - [x] LRU Cache (LeetCode 146)

### 4. Trees & Binary Search Trees (BST)
- **Patterns:** DFS (Pre/In/Post-order), BFS (Level Order), Tree Construction, LCA, Diameter/Path Sum.
- **Must-solve:**
  - [x] Maximum Depth of Binary Tree (LeetCode 104)
  - [x] Lowest Common Ancestor of a Binary Tree (LeetCode 236)
  - [x] Binary Tree Maximum Path Sum (LeetCode 124)
  - [x] Validate Binary Search Tree (LeetCode 98)
  - [x] Serialize and Deserialize Binary Tree (LeetCode 297)

### 5. Graphs
- **Patterns:** BFS, DFS, Topological Sort (Kahn's algorithm), Disjoint Set Union (Union-Find), Dijkstra, Bellman-Ford.
- **Must-solve:**
  - [x] Number of Islands (LeetCode 200)
  - [x] Clone Graph (LeetCode 133)
  - [x] Course Schedule (LeetCode 207)
  - [x] Network Delay Time (LeetCode 743)
  - [x] Alien Dictionary (LeetCode 269)

### 6. Dynamic Programming
- **Patterns:** 1D Linear DP, 0/1 Knapsack, Unbounded Knapsack, Longest Common Subsequence (LCS), Longest Increasing Subsequence (LIS), Grid DP, Interval DP.
- **Must-solve:**
  - [x] Climbing Stairs (LeetCode 70)
  - [x] Coin Change (LeetCode 322)
  - [x] Longest Increasing Subsequence (LeetCode 300)
  - [x] Edit Distance (LeetCode 72)
  - [x] Word Break (LeetCode 139)

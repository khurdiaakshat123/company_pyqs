## 📚 Topic-Wise Preparation

### 1. Data Structures & Algorithms (DSA)
- [DSA Roadmap & Master Checklist](topics/dsa/README.md)
  - Arrays & Two Pointers / Sliding Window
  - Strings & Pattern Matching
  - Linked Lists
  - Stacks & Queues (Monotonic Stack)
  - Trees, BST & Tries
  - Heaps & Priority Queues
  - Graphs (BFS, DFS, Dijkstra, Topo Sort, Union-Find)
  - Dynamic Programming (1D, 2D, Knapsack, Digit DP)

### 2. Core CS Fundamentals
High-yield, frequently asked interview questions:
- [Operating Systems (OS)](topics/core_cs/os.md) – Processes, Threads, CPU Scheduling, Deadlocks, Virtual Memory, Paging.
- [Database Management Systems (DBMS)](topics/core_cs/dbms.md) – ACID properties, Normalization, Indexing (B/B+ Trees), SQL vs NoSQL, Transactions.
- [Computer Networks (CN)](topics/core_cs/cn.md) – OSI & TCP/IP models, TCP vs UDP, DNS, HTTP/HTTPS, WebSockets, SSL/TLS.
- [Object-Oriented Programming (OOPS)](topics/core_cs/oops.md) – Encapsulation, Abstraction, Polymorphism, Inheritance, SOLID Principles.

### 3. System Design
- [System Design Prep Guide](topics/system_design/README.md) – Low-Level Design (Design Patterns, Class Diagrams) and High-Level Design (Scalability, Caching, Load Balancing, Microservices).

### 4. Aptitude & Reasoning
- [Aptitude Preparation Guide](topics/aptitude/README.md) – Formulas, shortcuts, quantitative aptitude, and logical puzzles.

## 🤝 How to Contribute

Contributions are welcome! If you recently gave an interview or solved an interesting previous year question:
1. Check the [Contribution Guidelines](CONTRIBUTING.md).
2. Fork the repository and create your branch (`git checkout -b feature/new-pyq`).
3. Add the question description, approaches (Brute-force to Optimal), and clean code.
4. Submit a Pull Request.

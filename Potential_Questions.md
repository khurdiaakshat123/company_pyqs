### 11. Multi-Level SQL Funding Aggregation (Adobe Backend OA 2024)

- **Company:** **Adobe**
- **Year / Cycle:** 2024 - 2025 / 2026 Campus & Off-Campus Drives
- **Drive / College Source:** `Adobe India On-Campus 2024`

#### 📋 Problem Statement & Specifications
Write a query to find the village(s) that received the maximum total funding across all projects in 2024, and for those top villages, list each project that received the highest individual allocation along with its rank.

#### 🗄️ Production SQL Solution
```sql
  WITH VillageTotals AS (
      SELECT village_id, SUM(funding_amount) AS total_fund,
             DENSE_RANK() OVER (ORDER BY SUM(funding_amount) DESC) as rnk
      FROM project_grants
      WHERE EXTRACT(YEAR FROM grant_date) = 2024
      GROUP BY village_id
  ),
  TopVillageProjects AS (
      SELECT p.village_id, p.project_id, p.funding_amount,
             DENSE_RANK() OVER (PARTITION BY p.village_id ORDER BY p.funding_amount DESC) as proj_rnk
      FROM project_grants p
      WHERE p.village_id IN (SELECT village_id FROM VillageTotals WHERE rnk = 1)
        AND EXTRACT(YEAR FROM p.grant_date) = 2024
  )
  SELECT village_id, project_id, funding_amount
  FROM TopVillageProjects
  WHERE proj_rnk = 1;
  ```

#### ⚙️ Problem Constraints
- Standard Online Assessment constraints apply.

#### 💡 Optimal Algorithmic Approach & Logic
Multi-level Common Table Expressions (CTEs) combined with window functions (`DENSE_RANK()`).

### 17. Request Queue Scheduling Across Least Busy Servers

- **Company:** **Amazon**
- **Year / Cycle:** 2024 - 2025 / 2026 Campus & Off-Campus Drives
- **Drive / College Source:** `Amazon Campus Placement 2024`

#### 📋 Problem Statement & Specifications
There are $K$ servers and a stream of incoming requests. Each request arrives at time $t$ and takes duration $d$. A request must be assigned to an available server with the minimum current load (number of requests handled), breaking ties with the smallest server index. If all servers are busy, drop the request. #### ⚙️ Problem Constraints
- Execution Time Limit: Bounded strictly by target complexity `$O(N \log K)$ Time, $O(K)$ Space.`.

#### ⏱️ Complexity Analysis
- **Target Bound:** $O(N \log K)$ Time, $O(K)$ Space.

```sql
  SELECT DISTINCT user_id 
  FROM (
      SELECT user_id, 
             transaction_date, 
             LAG(transaction_date, 1) OVER (PARTITION BY user_id ORDER BY transaction_date) as prev1,
             LAG(transaction_date, 2) OVER (PARTITION BY user_id ORDER BY transaction_date) as prev2
  ```

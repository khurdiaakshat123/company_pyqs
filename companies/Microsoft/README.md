# Microsoft Interview Questions & PYQs 🪟

## 🎯 Hiring Process Overview
- **Online Assessment (Codility):** 3 coding questions (typically 75–90 mins), with strict checks on corner cases and test coverage.
- **Technical Interviews:**
  - 3–4 Rounds: Focus heavily on clean code, string manipulation, trees, linked lists, and basic system design.
  - Discussion on past projects, internal mechanics of frameworks, and CS fundamentals (OS, DBMS).

## 💡 Key Focus Areas
- Linked Lists (Reversals, Cycle Detection, Flattening, Intersection)
- String Manipulation and Parsing
- Trees & Binary Search Trees
- Dynamic Programming (Standard classic variations)
- Operating Systems concepts (Multithreading, Deadlocks, Mutex vs Semaphore)

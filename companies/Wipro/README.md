# Wipro Online Assessment (OA) Guide & Multi-Year PYQs (2023 - 2025/2026) 💼

## 📌 OA Overview & Test Logistics
- **Assessment Platform:** **AMCAT (Aspiring Minds)** / **Superset**
- **Hiring Tiers:**
  - **Wipro Turbo:** 6.5 LPA (Requires high score in advanced coding + technical assessment)
  - **Wipro Elite (NTH - National Talent Hunt):** 3.5 LPA
- **Structure Breakdown (128 minutes total):**
  1. **Aptitude Section (48 mins):** Logical Reasoning (14 Q), Quantitative Ability (16 Q), English Verbal Ability (18 Q).
  2. **Written Communication (20 mins):** Essay writing on a given topic evaluated by automated AI scoring (grammar, vocabulary, relevance, length $\ge 200$ words).
  3. **Coding Section (60 mins, 2 Questions):**
     - Question 1: Easy (Arrays / String manipulation / Basic Math)
     - Question 2: Easy-Medium (Two pointers, Matrix traversal, Hash Table, DP basics)
- **Negative Marking:** None, but adaptive difficulty is enabled on AMCAT.

---

## 🎯 Question Pattern & Topics (Last 3 Years Analysis)
- **Basic Mathematics & Arrays:** Second largest element, array sum equilibrium, prime/fibonacci sequences, Kadane's algorithm.
- **String Processing:** Vowel/consonant counts, anagrams, palindrome verification, word reversal, longest substring.
- **Two Pointers & In-Place Ops:** Move zeros, pair with given sum, remove duplicates, Dutch National Flag.
- **Matrix Manipulations:** Row/column sum, matrix diagonal difference, matrix boundary sum.
- **Linked Lists & Stacks:** Reverse linked list, valid parentheses.

## 📝 Multi-Year College OA Question Bank (Past 3 Years)

### 2024 - 2025 / 2026 Campus & Off-Campus Drives

#### 1. Second Largest Element in Array without Sorting
- **College/Drive:** Wipro Turbo Campus 2024
- **Problem Summary:** Given an array of integers, find the second largest unique element without sorting the array.
- **Approach:** Single linear traversal maintaining `max1` and `max2`.
- **Complexity:** $O(N)$ Time, $O(1)$ Space.

#### 2. Password Strength / Character Diversity Count
- **College/Drive:** Wipro Elite NTH 2024
- **Problem Summary:** Return whether a string has at least 8 characters, at least 1 uppercase letter, 1 lowercase letter, 1 number, and 1 special symbol.
- **Complexity:** $O(N)$ Time, $O(1)$ Space.

#### 3. Maximum Subarray Sum (Kadane's Algorithm)
- **College/Drive:** Off-Campus Drive 2024
- **Problem Summary:** Given an integer array `nums`, find the subarray with the largest sum, and return its sum.
- **LeetCode Equivalent:** [53. Maximum Subarray](https://leetcode.com/problems/maximum-subarray/)
- **Complexity:** $O(N)$ Time, $O(1)$ Space.

#### 4. String Character Compression
- **College/Drive:** Campus Slot 1 (2024)
- **Problem Summary:** Convert `"aabbbcccc"` into `"a2b3c4"`.
- **Complexity:** $O(N)$ Time.

#### 5. Equilibrium Index of an Array
- **College/Drive:** Campus Slot 2 (2024)
- **Problem Summary:** Find an index such that the sum of elements at lower indices is equal to the sum of elements at higher indices.
- **Approach:** Total sum minus running prefix sum.
- **Complexity:** $O(N)$ Time, $O(1)$ Space.

#### 6. Trapping Rain Water (Wipro Turbo Track)
- **College/Drive:** Wipro Turbo National Drive 2024 / VIT Vellore
- **Problem Summary:** Compute total water trapped by elevation bars after rain.
- **LeetCode Equivalent:** [42. Trapping Rain Water](https://leetcode.com/problems/trapping-rain-water/)
- **Approach:** Two pointers inward from boundaries.
- **Complexity:** $O(N)$ Time, $O(1)$ Space.

#### 7. Longest Substring Without Repeating Characters
- **College/Drive:** Wipro Turbo 2024 / SRM University
- **Problem Summary:** Find length of longest substring without duplicate characters.
- **LeetCode Equivalent:** [3. Longest Substring Without Repeating Characters](https://leetcode.com/problems/longest-substring-without-repeating-characters/)
- **Approach:** Sliding window with hash map storing character positions.
- **Complexity:** $O(N)$ Time.

#### 8. Subarray Sum Equals K
- **College/Drive:** Pan-India Turbo Drive 2024
- **Problem Summary:** Total number of continuous subarrays whose sum equals $K$.
- **LeetCode Equivalent:** [560. Subarray Sum Equals K](https://leetcode.com/problems/subarray-sum-equals-k/)
- **Approach:** Running prefix sum with hash map frequency tracking.
- **Complexity:** $O(N)$ Time, $O(N)$ Space.

#### 9. Search in Rotated Sorted Array
- **College/Drive:** National Level Drive 2024
- **Problem Summary:** Search target element in a circularly rotated sorted array.
- **LeetCode Equivalent:** [33. Search in Rotated Sorted Array](https://leetcode.com/problems/search-in-rotated-sorted-array/)
- **Approach:** Modified binary search checking sorted half.
- **Complexity:** $O(\log N)$ Time, $O(1)$ Space.

#### 10. Palindrome Number Check Without String Conversion
- **College/Drive:** Wipro Elite 2024
- **Problem Summary:** Determine if integer is palindrome using `% 10` and `/ 10` arithmetic.
- **LeetCode Equivalent:** [9. Palindrome Number](https://leetcode.com/problems/palindrome-number/)
- **Complexity:** $O(\log_{10} N)$ Time, $O(1)$ Space.

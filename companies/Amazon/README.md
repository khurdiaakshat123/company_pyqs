# Amazon Interview Questions & PYQs 📦

## 🎯 Hiring Process Overview
- **Online Assessment (OA):** 
  - 2 Coding Questions (90 mins)
  - Work Style Assessment (Amazon 16 Leadership Principles alignment)
- **Technical Rounds:**
  - 3–4 rounds covering DSA, Low-Level Design (LLD), and System Architecture.
  - Every round devotes 15–20 minutes to Amazon's **Leadership Principles (LP)** using the STAR method (Situation, Task, Action, Result).

## 💡 Key Focus Areas
- HashMaps, Sets, and Frequency Counting
- Trees & Binary Search Trees (Lowest Common Ancestor, Traversals, Serialization)
- Breadth-First Search (BFS) on Matrices / Multi-source BFS (e.g., Rotting Oranges)
- Priority Queues (Top K Frequent, Merge K Sorted Lists)
- Object-Oriented Design (Locker Management System, Parking Lot, Unix File Search API)

# Google Interview Questions & PYQs 🔍

## 🎯 Hiring Process Overview
- **Online Assessment (OA):** 2 coding questions (60–90 minutes) focusing on DP, Graphs, or Greedy algorithms.
- **Technical Phone Screen:** 1 round (45 mins) - Live coding with clean code, edge cases, and algorithmic complexity analysis.
- **Onsite / Virtual Onsite:**
  - 3–4 Coding Rounds (DSA, algorithmic problem solving)
  - 1 Googleyness & Leadership Round (behavioral)

## 💡 Key Focus Areas
- Advanced Graph Algorithms (Topological Sort, Dijkstra, Tarjan's SCC, Bipartite matching)
- Dynamic Programming (State transition, optimization)
- Segment Trees, Fenwick Trees (Binary Indexed Trees)
- Monotonic Stacks and Queues
- Clean, modular, production-ready code with strong attention to boundary conditions

## 📌 Preparation Tips
1. **Clarify ambiguous requirements:** Google interviewers deliberately leave inputs or constraints underspecified. Ask clarifying questions.
2. **Think out loud:** Explain your thought process, evaluate time/space tradeoffs before writing code.
3. **Write test cases proactively:** Walk through positive, negative, and extreme edge cases without being prompted.

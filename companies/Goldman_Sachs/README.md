# Goldman Sachs Interview Questions & PYQs 🏛️

## 🎯 Hiring Process Overview
- **Aptitude & Coding Assessment:**
  - Quantitative Aptitude & Math (Probability, Permutations, Combinations, Algebra)
  - 2 Coding Questions
  - CS Fundamentals MCQs
- **Technical Rounds:**
  - 2–3 Technical Rounds focusing on DSA, Math/Probability puzzles, Java/C++ internals, collections, and databases.
  - Senior Director / Hiring Manager Round

## 💡 Key Focus Areas
- Probability, Combinatorics, and Puzzles (Monty Hall, 25 Horses, 8 Balls)
- Array manipulation and Hash Tables
- String Parsing and Compression
- Dynamic Programming (Grid DP, Stock Buy and Sell series)
- Database queries (Window functions, Subqueries)

# Atlassian Interview Questions & PYQs 🔷

## 🎯 Hiring Process Overview
- **Online Assessment:** HackerRank test with 3 algorithmic coding challenges (strict time and memory limits).
- **Technical Rounds:**
  - 1 DSA Problem Solving Round
  - 1 Code Design / LLD Round (Very interactive, writing actual working code with classes, interfaces, and unit tests)
  - 1 System Architecture / System Design Round
  - 1 Values & Behavioral Round (Atlassian Values)

## 💡 Key Focus Areas
- Clean, testable, object-oriented code with proper separation of concerns
- Concurrency, Thread Safety, Locks, and Race Conditions
- Rate Limiters, Voting Systems, Snake Game, File Systems
- Graph algorithms and Interval scheduling

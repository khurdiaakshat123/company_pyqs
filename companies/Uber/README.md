# Uber Interview Questions & PYQs 🚗

## 🎯 Hiring Process Overview
- **Online Assessment (CodeSignal):** 4 coding challenges (70 mins), scoring evaluated on General Coding Assessment (GCA) benchmark.
- **Technical Rounds:**
  - 2 Problem Solving & DSA Rounds (heavy focus on graphs and optimization)
  - 1 System Design / Machine Coding Round
  - 1 Hiring Manager & Culture Round

## 💡 Key Focus Areas
- Graph Algorithms (Dijkstra's shortest path, A* search, Network flow)
- Interval Scheduling & Sweep Line Algorithm
- QuadTree / Spatial Indexing / Geo-hashing concepts
- Concurrency and Scalable Systems
